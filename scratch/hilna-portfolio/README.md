## 🚀 Live Preview & Quick Start

### 1. View Locally
Simply double-click `index.html` to open it in any modern web browser, or run a lightweight local server:

**Using Python:**
```bash
# In this directory:
python -m http.server 8000
```
Then navigate to: `http://localhost:8000`

### 2. Free 1-Click Deployment to GitHub Pages
Since all code is pure semantic HTML5, CSS3, and vanilla JS with zero build steps or heavy dependencies:
1. Initialize Git in this directory (if not already done):
   ```bash
   git init
   git add .
   git commit -m "feat: initial release of Bento portfolio"
   ```
2. Create a new repository on your GitHub account (`hilnamanoharan2008-cmyk`) named `portfolio` or `hilnamanoharan2008-cmyk.github.io`.
3. Link and push your code:
   ```bash
   git remote add origin https://github.com/hilnamanoharan2008-cmyk/portfolio.git
   git branch -M main
   git push -u origin main
   ```
4. On GitHub, navigate to **Settings > Pages > Build and deployment**, choose branch `main` and folder `/ (root)`.
5. Your portfolio is instantly live worldwide!

## 💎 Features & Architecture

- **Bento-Grid Information Architecture**: Asymmetric card grid inspired by modern Apple and Linear design systems, highlighting educational background, core tech stack, creative coding, and design philosophy.
- **⚡ 30-Second Recruiter Snapshot Mode**: Dedicated modal/drawer summarizing "Who, What, Seeking" for fast recruiter scanning.
- **Dark & Light Mode**: Seamless theme switching with saved preference in `localStorage`.
- **One-Click Contact & Copy**: Instant clipboard copy with visual toast notifications, direct LinkedIn and GitHub links, plus an interactive mailto launcher.
- **Ultra-Lightweight & Fast**: Zero framework bloat, sub-second load times, and 100% responsive down to small mobile screens.
